# Pib_Roboter

## Projektbeschreibung

**Projektname:** Pib_Roboter  
**Ziel:** Mit einem Raspberry Pi-basierten Roboter (kurz: PiB-Roboter) das bekannte "Haus vom Nikolaus" auf Papier zeichnen.

Das Projekt kombiniert Robotik, Programmierung und ein klassisches Zeichenspiel. Der Roboter soll autonom eine Figur zeichnen, die aus einem Quadrat mit zwei Diagonalen und einem Dach besteht – idealerweise in einem einzigen durchgehenden Linienzug, ohne den Stift abzusetzen (wie beim Haus vom Nikolaus).
